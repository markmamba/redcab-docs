## TL;DR

- Read [Documentation system](/docs/00-09-meta/conventions/documentation-system#documentation-system) first if you work on docs structure, Catalog revamp, or implementation specs.
- Then: **Glossary → Business rules → Requirements → Roadmap → Open questions**.
- Use [Explainers](/docs/70-79-business/explainers) for plain-language walkthroughs ([ASD-STE100](/docs/00-09-meta/conventions/prose-and-ste100) Tier A); they link to normative sources.
- Engineering detail lives under [Architecture](/docs/30-49-domains) and [Engineering](/docs/90-99-engineering-meta).
- Catalog normative docs (pilot): [Catalog domain](/docs/30-49-domains/catalog/).

## Recommended path

1. [Glossary](/docs/70-79-business/business-rules/glossary) — shared vocabulary
2. [Business rules (invariants)](/docs/70-79-business/business-rules/invariants) — what must never break
3. [Functional requirements](/docs/70-79-business/requirements/functional-requirements) — observable behavior by context
4. [Open questions](/docs/70-79-business/planning/open-questions) — unresolved decisions

## By role

| Role | Focus |
| --- | --- |
| Executive / sponsor | [Key decisions](/docs/70-79-business/explainers/key-decisions) → roadmap → open questions |
| Product owner | Glossary → invariants → FR for your context → [traceability](/docs/70-79-business/requirements/traceability-matrix) |
| Business analyst / ops | Glossary → [booking lifecycle](/docs/70-79-business/explainers/booking-lifecycle) → [money flow](/docs/70-79-business/explainers/money-flow) → invariants |
