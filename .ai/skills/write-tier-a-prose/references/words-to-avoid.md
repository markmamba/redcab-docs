# Words to avoid (Tier A)

Use a plain alternative. Glossary terms still win when the doc is Tier B normative.

| Avoid | Prefer |
| --- | --- |
| leverage | use |
| utilize | use |
| ensure | make sure / verify / the system checks |
| facilitate | help / allow |
| robust | strong / reliable (or delete) |
| seamless | (delete; describe the actual UX) |
| simply / just | (delete) |
| aforementioned | (repeat the noun or use "this") |
| E2E | end-to-end (spell out once) |

Also avoid idioms: "circle back", "low-hanging fruit", "out of the box".
