# Words to avoid

Use a plain alternative. When a glossary term exists, use the [Glossary](/docs/70-79-business/business-rules/glossary) term.
- Use the replacement, or define the word in plain words on first use when no replacement exists.
- A word used against its own precise meaning has no rescue, so replace it.

Three lists: borrowed and figurative words, the finance exception, and AI vocabulary.

## Borrowed and figurative words

| Avoid | Use instead |
| --- | --- |
| immutable | cannot change, and who or what stops the change |
| snapshotted | copied from |
| no-op | does nothing, has no effect |
| denormalised | copied into this table |
| idempotent | safe to run twice |
| tuple (for a combination of values) | combination, because in SQL a tuple is a row |
| load-bearing | important, and removing it breaks X |
| red herring | looks like the cause, but is not |
| leaks into, cascades | spreads to |
| move the needle | make a real difference |
| north star | main goal |
| low-hanging fruit | the easy wins first |
| circle back | follow up later |
| out of the box | by default |
| dial in | adjust |
| ratchet up | increase step by step |
| rabbit hole | deep investigation |
| table stakes | the minimum needed |
| moving parts | things that change, dependencies |
| the sweep, swept | name the job and its effect: "the nightly expiry job releases the seats" |
| re-arm, fire again | sends again, runs again |
| suppose | assume, or state the case |
| leverage, utilize | use |
| ensure | make sure, verify, or state what checks it |
| facilitate | help, allow |
| robust, seamless | describe the actual behavior or UX |
| simply, just, aforementioned | delete or repeat the noun |
| E2E | end-to-end (spell out once) |
| serves (a purpose) | is for, does |

Also avoid idioms: "circle back", "low-hanging fruit", "out of the box".

## The finance exception

A finance term of art is allowed in payment and booking money docs when the first use defines it in plain words.

## AI vocabulary

| Avoid | Use instead |
| --- | --- |
| delve into | look at, investigate |
| comprehensive | say what is covered |
| crucial, vital | important, or be specific |
| pivotal | important, or be specific |
| harness (verb) | use |
| empower | say what becomes possible |
| cutting-edge, state-of-the-art | name the technology |
| game-changer | describe the change |
| underscore (verb) | show |
| Moreover, Furthermore | start a new sentence, or "also" |
| In conclusion, To summarize, In summary | write the conclusion itself |
| It's worth noting that, It is important to note | state the fact |
| Let me know if you have any questions, I hope this helps, Happy to help | end on the last point |
| Great question, Looking at the code, Based on my analysis, I'll go ahead and | state the finding or do the thing |

No emojis in any text for the team.
